# 桌邊 Tablemate

繁體中文桌遊收藏、借用請求、桌遊團及空閒時間管理網站的互動原型。

> 目前為本機介面原型：資料只保留在當次頁面記憶體，重新整理會還原。Google 登入、Supabase、BGG API 與真實跨使用者通知尚未接入。收藏圖片及評分為示意資料。

## Windows 本機啟動

需先安裝 Node.js。於本資料夾開啟 PowerShell：

```powershell
npm run dev:test
```

瀏覽器開啟 http://127.0.0.1:5173 。停止服務按 Ctrl+C。無需額外安裝 npm 套件；也可直接以瀏覽器開啟 index.html。

## 目前可操作的原型

- 桌遊收藏：中英文搜尋、複合篩選、難度及推薦度排序、卡片／條列切換、凍結名稱欄、自己的收藏新增編輯刪除、Excel 匯出。
- 同團收藏：相同遊戲合併顯示，多位擁有者頭像及各自的推薦度、借出狀態。
- 借用請求：選擇擁有者、必填聯絡方式、同意／婉拒／要求補充聯絡方式及示範通知。
- 桌遊團：名稱、簡介、遊戲取向標籤搜尋，公開直接加入／不公開申請加入、團主／管理員／一般成員、團主移交及退出遞補、自訂團內通知。
- free time：四種狀態（有空、沒空、不確定、未填），日期範圍、每週重複、預設時段與十分鐘微調、連續長條呈現。
- 揪團月曆：點日期開啟團員時間視窗，直／橫式、半小時虛線、凍結標題與滑鼠跟隨提示。
- 設定：暱稱、頭像、常用聯絡方式、展示方式、12／24／30 小時制。三十小時制指當日 06:00 至隔日 06:00（30:00）。

## BGG API 預定用途

取得 BoardGameGeek 應用程式授權後，預計提供桌遊搜尋、選取、資料預覽與匯入，包含英文名稱、人數、預計遊玩時間、機制、難度、評分、排名與封面等可取得的欄位。匯入前可手動調整中文名稱與個人資料，沒有 BGG 資料也可手動新增。

目前尚未串接 BGG，未使用實際 BGG API Token，也未宣稱範例數值是即時 BGG 資料。正式整合時將依當時官方授權條款、速率限制與標示要求處理；Token 不放在前端或儲存庫。
